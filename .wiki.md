# Project Summary
Folio is a full-stack resume creation, editing, and publishing tool. Users can organize their experience, build resume websites through conversation or HTML editing, apply built-in or custom styles, save versions, download HTML, and publish public pages.

First-time conversational resume creation takes users to “My Resumes,” where a progress card opens the editor when generation is complete. The homepage is designed to reduce vertical scrolling, and its left sidebar no longer displays the tagline “把经历写清楚，网站自然就好看。”

# Project Module Description
- **Authentication and workspace**: Supports Atoms Cloud login and resume, version, and publication management.
- **Resume creation**: The homepage and example page provide creation entry points. First-time generation redirects to “My Resumes,” where a progress card appears before opening the editor.
- **Resume content and styles**: Organizes personal materials and applies built-in styles or generates, selects, and deletes custom styles.
- **Conversational editing**: Modifies pages using resume content, applied HTML, and recent messages. Experience entries can be found by their existing titles and edited directly.
- **HTML editing and export**: Previews, edits, applies, and downloads HTML. Publishing and export use the applied version.
- **Publishing and sharing**: Publishes snapshots accessible without signing in.
- **Model settings**: Supports compatible OpenAI API endpoints, tokens, and model IDs. Tokens are encrypted server-side. Custom styles can use built-in presets when no model is configured.
- **Backend API and persistence**: Manages resumes, styles, messages, versions, model settings, file storage, and publication snapshots, with ownership checks.

# File Description Inventory
- **Documentation and startup**: `README.md` covers the product, quick start, and deployment; `DESIGN.md` describes product design; `app/start_app_v2.sh` starts the full stack.
- **Homepage and creation flow**: `frontend/src/pages/Index.tsx` provides the homepage and creation entry point; the left-sidebar tagline has been removed. `ExamplePage.tsx` also provides a creation entry point. `ResumesPage.tsx` displays generation progress and opens the editor when ready.
- **Resume workspace**: `Workspace.tsx` implements resume editing and style interactions; `frontend/src/lib/folio.ts` encapsulates frontend resume and style logic.
- **Resume editing and API**: `backend/prompts/resume-assistant.md` guides conversational editing; `backend/services/folio_profile.py` normalizes profile data and applies patches; `backend/routers/folio.py` provides resume APIs.
- **Versions and styles**: `VersionsDialog.tsx` provides version and style dialogs; `backend/services/folio_styles.py` implements custom style logic; `backend/prompts/resume-style.md` provides style-generation prompts.
- **Rendering and backend application**: `backend/services/folio_render.py` renders resume pages; `backend/main.py` registers the application and routes. `core/`, `models/`, `schemas/`, `data_models/`, and `alembic/` handle configuration, entities, API structures, business model definitions, and migrations. `lambda_handler.py` provides the Lambda entry point.
- **Frontend shared code and build**: `contexts/` manages authentication state; `api/` wraps service calls; `components/` contains UI components; `public/` stores static assets; `package.json`, `vite.config.ts`, and `plugins/` support dependencies, builds, and tests; `prerender/` handles blog prerendering.

# Technology Stack
- **Frontend**: React, TypeScript, Vite, Tailwind CSS.
- **Backend**: Python, FastAPI, SQLAlchemy, Alembic.
- **Cloud integration**: Atoms Cloud authentication, API, and storage capabilities.
- **AI**: Configurable models compatible with the OpenAI API; built-in style presets are available when no model is configured.
- **Deployment and testing**: Lambda backend entry point; frontend includes Playwright configuration and plugin tests.

# Usage
See `README.md` for the user quick start and deployment guide. For local development:

1. **Install frontend dependencies**
   ```bash
   cd app/frontend
   npm install
   ```

2. **Install backend dependencies**
   ```bash
   cd app/backend
   python -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   ```

3. **Configure the environment**  
   Set database, authentication, and storage parameters for the deployment environment. Review `backend/core/config.py` and frontend configuration. To use an AI model, configure its API endpoint, token, and model ID in model settings.

4. **Initialize the database**
   ```bash
   cd app/backend
   alembic upgrade head
   ```

5. **Develop and build the frontend**
   ```bash
   cd app/frontend
   npm run dev
   npm run build
   ```

6. **Start the backend or full stack**  
   From `app/backend`, run `uvicorn main:app --reload` to start the backend, or use `app/start_app_v2.sh` to start the project.
